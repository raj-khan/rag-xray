# Security Guidelines

Everyone at Orbita Labs is responsible for keeping customer data safe.

## Devices

All work laptops must use full-disk encryption and lock automatically after 5 minutes of inactivity. Personal devices may not be used to access customer data.

## Passwords and MFA

Store all work passwords in Vaultbox, the company password manager. Multi-factor authentication is required on every work account. Hardware security keys are required for engineers with production access.

## Reporting incidents

If you suspect a security incident, such as a lost laptop, a leaked API key or a suspicious login, report it in the #sec-incidents channel within 1 hour. Do not try to investigate it yourself.

## Phishing

Forward suspicious emails to phishing@orbita.example. Never enter your credentials on a page you reached from an email link. The security team runs a phishing simulation every quarter.

## Access reviews

Managers review their team's access to production systems every 6 months. Access that is no longer needed is removed within 2 working days of the review.
